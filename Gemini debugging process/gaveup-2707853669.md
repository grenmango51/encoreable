## 5. Diagnostic Investigation: Why `both@spectator` Stalled and Gave Up

### A. The Non-Linear Draining Mechanics on Double-Resisted Targets
In Reg M-C Champions doubles, Mega Golisopod is a **Bug / Steel** type with base **150 Attack** and base **175 Defense**, possessing the ability `Tough Claws` (1.333× multiplier to contact moves).
When `p1b: Golisopod` uses `Leech Life` (80 BP Bug-type contact move) against `p2b: Golisopod`:
1. Bug is resisted by Bug (0.5×) and resisted by Steel (0.5×), resulting in a net **0.25× double-resistance**.
2. Damage dealt in Showdown:
   $$\text{Damage} = \left\lfloor\left(\frac{2 \times 50 / 5 + 2}{50} \times 80 \times \frac{\text{Atk}_{\text{p1}}}{\text{Def}_{\text{p2}}} + 2\right) \times \frac{4}{3} \times 1.5 \times 0.25 \times \text{roll}\right\rfloor$$
   Because base Def is 175 and the type multiplier is 0.25×, the raw damage dealt is extremely small (typically 12–18 HP).
3. Drain recovery is defined as:
   $$\text{Drain} = \left\lceil\frac{\text{Damage}}{2}\right\rceil$$
   which is then converted to an integer percentage of the attacker's Max HP:
   $$\text{DrainPct} = \text{round}\left(100 \times \frac{\text{Drain}}{\text{MaxHP}_{\text{p1}}}\right)$$
4. Because the damage value is small, a single damage point difference toggles the drain recovery percentage between `57/100` and `58/100`.
