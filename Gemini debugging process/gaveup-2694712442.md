## 5. Root Cause Analysis: The Turn 2 `2.10` `pairs` Bug & Why `p1@p2` / `p2@p1` Gave Up While `both@spectator` Fluked a Pass

### A. Mechanical Root Cause in `reconstruct.mjs`: `pairs` Rejects `[10, 5, 5]` Over `[10, 1, 1]` at Line 1984
In `Muddy Water`'s `secondaries()` loop (`sim/battle-actions.ts:1135-1145`), Showdown rolls `battle.random(100)` sequentially for each hit target:
- `draw A` (`p2a: Annihilape`): if `< 30`, immediately emits `|-unboost|p2a: Annihilape|accuracy|1` (`2.10`) followed by `|-ability|p2a: Annihilape|Defiant|boost` and `|-boost|p2a: Annihilape|atk|2`.
- `draw B` (`p2b: Tyranitar`): if `< 30`, emits `|-unboost|p2b: Tyranitar|accuracy|1`.

On Turn 2, both `sampler(1 ^ 0x5eed)` (used by Searches 1–3) and `sampler(2 ^ 0x5eed)` (`resample: 1`, Search 4) rolled `< 30` on **both** `draw A` and `draw B`. Under `resolveTurn(2, ...)` (`scripts/lib/reconstruct.mjs:1786-2045`):
1. `scoreOf(run, 2)` starts at `[10, 1, 1]` (`index = 10`, `fields = 1`, `shared = 1`), comparing `got = "|-unboost|p2a: Annihilape|accuracy|1"` against `want = "|move|p1a: Gholdengo|Make It Rain|p2a: Annihilape|[spread] p2b"`.
2. **Single-die scan (`lines 1917-1952`)**: `canReach` admits `draw A` (`gotHard.length === 10 <= 10`). Flipping `draw A = 99` suppresses `p2a`'s unboost, **but `draw B` still rolls `< 30`**, producing `got = "|-unboost|p2b: Tyranitar|accuracy|1"` — which still scores `[10, 1, 1]`. Nothing commits.
3. **Two-chance `pairs` scan (`lines 1973-1994`)**: `pairs` flips **both** `draw A = 99` and `draw B = 99` together, cleanly clearing `Muddy Water` and advancing execution to `2.10`: `Make It Rain`. Because `Make It Rain` defaults to hitting both 95%-accuracy targets, Showdown emits:
   ```
   |move|p1a: Gholdengo|Make It Rain|p2a: Annihilape|[spread] p2a,p2b
   ```
   Compared against `want`, **`fields` jumps from `1` to `5`** (`['', 'move', 'p1a: Gholdengo', 'Make It Rain', 'p2a: Annihilape']` all match!), giving **`scoreOf(probe, 2) = [10, 5, 5]`**.
4. **The Bug (`reconstruct.mjs` line 1984)**:
   ```js
   if (scoreOf(probe, t)[0] > score[0]) {
     commit(a.i, va);
     commit(b.i, vb);
     committed = true;
     break pairs;
   }
   ```
   Because line 1984 checks **`scoreOf(probe, t)[0] > score[0]`** (`10 > 10` $\to$ `false`) instead of **`outranks(scoreOf(probe, t), score)`**, `pairs` **discards the `(draw A = 99, draw B = 99)` fix**! Once `[10, 5, 5]` had been committed, `steerDice` (`hitStepAccuracy` at line 1042) would immediately have seen `p2a` missing from `[spread] p2b` and flipped `Make It Rain`'s accuracy roll on `p2a` to `99`, solving Turn 2 in one step. Instead, `resolveTurn(2)` exits with `ended = "stuck"` (or `"probes"` at `maxProbes = 150`) and prints `got |-unboost|p2a: Annihilape|accuracy|1`.

### B. Why Fallback Rebuilds Cycled Across Starts 1–5 (and Why `Gholdengo spe 18` Fluked a Pass in Start 6)
