## 5. Root Cause Analysis: Why Spectator Inference Gave Up

### 5.1 The Instruct Target Ambiguity in Replay Protocol vs Simulation
In Pokémon Showdown, `Instruct` has a target definition of `'normal'` (any adjacent Pokémon on the field, ally or enemy).
When `Instruct` is recorded in standard Showdown replays, if the move fails or if the target has not yet acted in that turn, Showdown frequently emits an un-targeted line:
```
|move|p2b: Oranguru|Instruct||[still]
|-fail|p2b: Oranguru
```
In `reconstruct.mjs` line 187:
```javascript
const target = parts[4] && parts[4].includes(': ') ? parts[4] : null;
```
Because `parts[4]` was empty, `action.target` was parsed as `null`. Consequently, `reconstruct` lacked any preferred target constraint and was forced to treat the target as a search variable.

### 5.2 The Choice Variant Ordering Trap (`+1` vs `+2`)
In `reconstruct.mjs`:
```javascript
const options = targetOptions(side, i, moveTarget, preferred);
suffix = options[state.nextVariantDigit(options.length)];
```
When `preferred` is null, `targetOptions` generates the target order:
1. Option 0: `+1` (`p1a: Blaziken`)
2. Option 1: `+2` (`p1b: Primarina`)
3. Option 2: `-1`
4. Option 3: `-2`

In base reconstruction, variant 0 maps to `+1` (`p1a: Blaziken`). However, the mimic replay was played with AI seed `"8553,45711,65168,62312"`, which caused the mimic player to aim at `p1b: Primarina` (`+2`).
Whenever reconstruct simulates Turn 3 with variant 0, Oranguru executes `Instruct` on `p1a: Blaziken`, directly triggering the diff at 3.11.

### 5.3 Why `speed.mjs` Cannot Intervene
In `scripts/lib/inference/infer.mjs`, the engine checks whether a line mismatch is an action ordering failure:
```javascript

const who = l => (/^p[1-4][a-d]?: /.test(String(l || '').split('|')[2] || '') ? String(l).split('|')[2] : null);
const order = (who(diff.actual) && who(diff.expected) && who(diff.actual) !== who(diff.expected))
  || (kind(diff.actual) !== kind(diff.expected) && ACTION_START.has(kind(diff.actual)) && ...);
```
At line 3.11:
- `diff.expected`: `|move|p2a: Oranguru|Instruct|p1b: Primarina`
- `diff.actual`: `|move|p2a: Oranguru|Instruct|p1a: Blaziken`
Here, `who(diff.actual)` is `p2a: Oranguru` and `who(diff.expected)` is `p2a: Oranguru`. Both are identical (`who === who`).
Both actions have kind `'move'`.
Therefore, `order` evaluates to **`false`**. The engine correctly determines that this is not a speed sort failure, so `speed.mjs` has no role and cannot reorder turns.

## 7. Search Limits Analysis & Conclusion

### Limits Hit Analysis
The search reached `limits: ["backtracks", "fallbackRebuilds", "probes", "searches"]`:

1. **`searches`**:
   - Primary terminal condition. In `infer.mjs`, when candidate bounds remain identical across rounds and fallback fails to advance past the failing turn, search level increments until `++level >= budgets.length`, terminating the engine with `stop = 'searches'`.
2. **`fallbackRebuilds`**:
   - Triggered when single fallback attempts exhausted their allocated rebuild budget (8 rebuilds in `default`, 32 in `wide`, 128 in `widest`) without finding any stat permutation that reproduced Turn 3 line 11.
3. **`probes`**:
   - Triggered in `reconstruct.mjs`. Backtracking simulations through choice and damage combinations accumulated 256,007 total probes before exhausting the search ceiling.
4. **`backtracks`**:
   - Triggered in `reconstruct.mjs` during early turns (Turns 1 and 2) when resolving multi-target spread damage rolls (Expanding Force, Heat Wave, Hyper Voice).

### Diagnostic Conclusion
Match `mimic:gen9championsvgc2026regmcbo3-2704629244` illustrates a fundamental **action target divergence trap decoupled from stat dimensions**:
1. On Turn 3, Oranguru used `Instruct` targeting `p1b: Primarina` in the mimic ground-truth battle.
2. In spectator reconstruction, because the original Showdown replay logged an untargeted failed move (`Instruct||[still]`), reconstruct generated target options in default slot order (`+1` = `p1a: Blaziken`, `+2` = `p1b: Primarina`).
3. Reconstruct tested option 0 (`+1`), creating an immediate protocol mismatch on line 3.11 (`wanted Instruct|p1b: Primarina, got Instruct|p1a: Blaziken`).
4. Reconstruct invoked `fallback` on Turn 3. However, `fallback` is architected exclusively to mutate **Stat Points** (HP, Atk, Def, SpA, SpD, Spe) with zero backtracking.
5. Because stat mutations have zero influence on target selection or move variant ordering, fallback tested hundreds of stat combinations that either reproduced the exact same target mismatch at line 3.11 or caused early damage mismatches at lines 3.1–3.10.
6. The spectator engine remained trapped at Turn 3 for 49 rounds across all four search phases, accumulating 256,007 probes over 2,560.4 seconds before giving up with zero candidate spreads pruned.
