## 5. Root Cause Analysis: Why Spectator Inference Gave Up

### 5.1 The Speed Tie / Natural Speed Inversion Trap
1. In competitive VGC, Archaludon has a base Speed of **85**, while Milotic has a base Speed of **81**.
2. With 0 Speed Stat Points:
   - Archaludon (Bold nature): $(85 + 0 + 20) = \mathbf{105}$ Speed.
   - Milotic (Calm nature): $(81 + 0 + 20) = \mathbf{101}$ Speed.
3. Therefore, unless Milotic invests at least 5 Stat Points into Speed (reaching 106 Speed), Archaludon is naturally faster.
4. Smogon usage distributions for Milotic overwhelmingly favor pure defensive bulk (e.g., `32 HP / 32 Def / 2 SpD` with 0 Spe). Conversely, Archaludon frequently runs 0 to 16 Speed.
5. Consequently, every guess drawn from defaults or usage priors places Archaludon faster than Milotic, generating an upkeep residual execution order where Archaludon heals before Milotic.

### 5.2 The Upkeep Residual Speed Coupling
In Pokémon Showdown, end-of-turn field and item residuals (`eachEvent('residual')`) execute in descending Speed order of the active Pokémon on the field.
On Turn 4, both Milotic and Archaludon held `Leftovers` and were grounded on `Grassy Terrain`.
Because both Pokémon trigger two consecutive healing events:
- If Milotic is faster: `[Milotic Terrain] -> [Milotic Leftovers] -> [Archaludon Terrain] -> [Archaludon Leftovers]`
- If Archaludon is faster: `[Archaludon Terrain] -> [Archaludon Leftovers] -> [Milotic Terrain] -> [Milotic Leftovers]`
The simulator prints the first line of the faster Pokémon immediately after the weather line. Any speed inversion causes an immediate, catastrophic line-order divergence.

### 5.3 Why `speed.mjs` Cannot Deduce the Rule Automatically
In `scripts/lib/inference/speed.mjs`:
```javascript
// The log diverged inside an event sort on the HP alone...
// P's handler is the one for the same effect as Q's - both Pokemon's
// Perish Song counts, both Leftovers - or the one whose effect the
// replay's line names...
```
When `rebuilt` produces `|-heal|p2a: Archaludon|82/100|[from] Grassy Terrain` while the expected line is `|-heal|p1a: Milotic|...`:
1. The engine checks if the event sort is an `eachEvent` or `fieldEvent`.
2. However, because both Grassy Terrain and Leftovers heal at identical 6% increments, and because subsequent rounds diverged on Leftovers (`|-heal|p1a: Milotic|82/100|[from] item: Leftovers`), the effect names mismatched (`hit.item.effect` was Grassy Terrain, but `prefix.observedLine` was Leftovers).
3. Even when `speed.mjs` registered that Milotic preceded Archaludon, asserting `Milotic Spe > Archaludon Spe` creates an insoluble tension with early-turn damage constraints.

### 5.4 The Single-Dimensional Fallback Failure Loop
When `infer.mjs` encounters repeated rebuild failures on Turn 4, it invokes `fallback(seen, start, ...)`:
- Fallback systematically modifies one stat dimension at a time across candidate Pokémon:
  1. **Milotic Speed**:

## 7. Search Limits Analysis & Conclusion
