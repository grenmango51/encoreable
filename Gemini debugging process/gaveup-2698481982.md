## 6. Spectator Search Pathology (`both@spectator`)

### Root Cause 1: Universal Integer Percentage Truncation Across Both Sides
In Channel 0 (spectator view), neither player's exact HP is visible. All damage, recoil, and healing events appear only as integer percentages:
$$\text{pct} = \left\lfloor \frac{\text{currentHP}}{\text{maxHP}} \times 100 \right\rfloor$$
Because max HP for every Pokémon on both sides is an unobserved variable ($base + SP + 75 \in [base+75, base+107]$), each integer percentage represents a discrete bucket of $1.5 \dots 2.3$ actual HP. Every single damage exchange involves 4 simultaneous unknowns: Attacker offensive stat, Defender defensive stat, Defender max HP, and the RNG damage roll.

### Root Cause 2: The Turn 4 Recoil / Sitrus Berry Rounding Trap
On Turn 4, P1 Incineroar uses Flare Blitz on P2 Farigiraf:
1. Farigiraf takes damage $D$.
2. Incineroar takes recoil damage $R = \lfloor D \times 0.33 \rfloor$.
3. Incineroar's residual HP is $\text{HP}_{\text{res}} = 119 - R$.
4. The spectator recoil damage line requires:
   $$\left\lfloor \frac{\text{HP}_{\text{res}}}{\text{maxHP}_{\text{Inc}}} \times 100 \right\rfloor = 42\%$$
5. Because $\text{HP}_{\text{res}} \le \lfloor \text{maxHP}_{\text{Inc}} / 2 \rfloor$, Incineroar's Sitrus Berry consumes and heals $H = \lfloor \text{maxHP}_{\text{Inc}} / 4 \rfloor$.
6. Incineroar's final HP is $\text{HP}_{\text{final}} = \text{HP}_{\text{res}} + H$.
7. The spectator heal line requires:
   $$\left\lfloor \frac{\text{HP}_{\text{final}}}{\text{maxHP}_{\text{Inc}}} \times 100 \right\rfloor = 66\%$$

With ground truth values ($\text{maxHP} = 202$, $R = 34$, $\text{HP}_{\text{res}} = 85$, $H = 50$, $\text{HP}_{\text{final}} = 135$):
- Recoil percentage: $85 / 202 = 42.079\% \rightarrow \mathbf{42\%}$.
- Heal percentage: $135 / 202 = 66.83\% \rightarrow \mathbf{66\%}$.

Notice how razor-thin the tolerance is:
- $85 / 202 = 0.42079$ is just **$0.08\%$ above the floor of $42.00\%$**.
- If recoil is $33$ instead of $34$ ($\text{HP}_{\text{res}} = 86$):
  - Recoil: $86 / 202 = 42.57\% \rightarrow 42\%$.
  - Heal: $(86 + 50) / 202 = 136 / 202 = 67.33\% \rightarrow \mathbf{67\%}$ (**Differs on Heal!**).
- If recoil is $35$ instead of $34$ ($\text{HP}_{\text{res}} = 84$):
  - Recoil: $84 / 202 = 41.58\% \rightarrow \mathbf{41\%}$ (**Differs on Recoil!**).

This creates an extreme 1-HP knife-edge: any candidate guess whose damage roll, Incineroar Atk, Farigiraf Def, or Incineroar max HP shifts the recoil by even a single HP will satisfy one line but fail the other.
