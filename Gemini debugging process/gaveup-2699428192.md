## 4. Search Limits Hit & Stopping Reason

### Stopping Reason
`stop: "searches"`

In `scripts/lib/inference/infer.mjs`:
- The inference loop runs across 4 sequential restart attempts when search stalls:
  1. Default start (`start: 'default'`)
  2. Usage prior start (`start: 'usage'`)
  3. Wide fallback start (`wide: true`, fallback budget scaled by $4$)
  4. Widest budget start (`widest: true`, entire search budget scaled by $4$)
- Within each start, when `unchanged` is true (candidate spread bounds do not advance), search levels increment (`level = 0, 1, 2, 3, 4`).
- When `level >= budgets.length` (4 levels) on the final start (`widest`), the engine executes:
  ```javascript
  if (++level >= budgets.length) { stop = 'searches'; break; }
  ```
- Because `inf.complete === false` and `SEARCH_LIMITS.has('backtracks' | 'fallbackRebuilds' | 'probes') === true`, `result` was assigned `'GAVE UP'`.

1. `fallbackRebuilds`: Triggered at Turn 6 fallback when the allocated fallback rebuild count exceeded the limit (`spent >= FALLBACK_REBUILDS * S * W`, where limit was 8 rebuilds on default/usage, 32 on wide, 128 on widest).
2. `probes`: Triggered in `reconstruct.mjs` during rebuild search when probe count reached the budget limit.
3. `backtracks`: Triggered in `reconstruct.mjs` during rebuild search when backtrack count reached the budget limit.
4. `searches`: Triggered in `infer.mjs` when all levels in `budgets` were exhausted across all restarts.

### Mechanics of the Substitute Failure Condition
1. **Showdown Substitute Mechanic (`data/moves.ts`)**:
   ```typescript
   if (pokemon.hp <= pokemon.maxhp / 4) {
     this.add('-fail', pokemon, 'move: Substitute', '[weak]');
     return null;
   }
   ```
   Substitute fails if and only if $HP \le \lfloor \text{maxHP} / 4 \rfloor$.
2. **Showdown Champions Format Percentage Reporting (`runtime/dist/sim/pokemon.js`)**:
   ```javascript
   const percentage = Math.floor(100 * this.hp / this.maxhp) || 1;
   shared = `${percentage}/100`;
   ```
   Channel 0 (spectator) displays $\lfloor 100 \times HP / \text{maxHP} \rfloor$.
3. **Mathematical Constraint Imposed by Protocol**:
   - On Turn 4, the displayed percentage was `25/100`:
     $$\lfloor 100 \times HP / \text{maxHP} \rfloor = 25 \implies HP / \text{maxHP} \ge 0.25$$
   - On Turn 6, Substitute failed with `[weak]`:
     $$HP / \text{maxHP} \le 0.25$$
   - Conjointly, these two conditions force:
     $$HP / \text{maxHP} = 0.25 \quad (\text{exactly } 1/4)$$
   - Therefore, $\text{maxHP}$ must be an exact multiple of 4, and Kingambit's Kowtow Cleave damage must equal exactly $0.75 \times \text{maxHP}$.
4. **Values in the Mimic Battle**:
   - Garchomp base HP = 108. With planted SP = 9:
     $$\text{maxHP} = 108 + 9 + 75 = 192 \quad (192 \equiv 0 \pmod 4, \quad 192 / 4 = 48)$$
   - Garchomp-Mega-Z base Def = 85. With planted SP = 0: Def stat = $85 + 0 + 20 = 105$.
   - Kingambit base Atk = 135, Adamant (+10%). With planted SP = 32: Atk stat = $\lfloor (135 + 32 + 20) \times 1.1 \rfloor = 205$. At +1 boost: Atk = $\lfloor 205 \times 1.5 \rfloor = 307$.
   - Kowtow Cleave (85 BP) dealt exactly 144 damage ($144 / 192 = 0.75$).
   - Remaining HP was $192 - 144 = 48$ ($48 / 192 = 0.25$, displaying `25/100`).
   - At Turn 6, $48 \le 192 / 4 = 48$, triggering `|-fail|p2a: Garchomp|move: Substitute|[weak]`.

### Why the Search Exhausted its Budget in `both@spectator`
1. **Absence of `|-fail|` hook in `evidence.mjs`**:
   `evidence.mjs` hooks damage, recoil, heals, stat boosts, speed sorts, and substitute breaks, but does not parse or evaluate `|-fail|` protocol lines. As a result, `settle` and `evidencePass` do not constrain candidate spreads for Kingambit (Atk) or Garchomp (HP, Def), nor enforce the modulo 4 constraint on Garchomp's HP.
2. **Behavior of Player Views vs Spectator View**:
   - In `p1@p2`, Player 1's side is hidden, but Player 2 is known. Delphox/Kingambit/Floette stats were inferred within 3 rounds because Player 2's Garchomp stats were exact.
   - In `p2@p1`, Player 1's stats (including Kingambit's exact 32 Atk) are known. Single-stat fallback on Turn 6 for Garchomp def 0 succeeded at round 5 (`fallback on turn 6: Garchomp def 0 - reproduces it, 7.1s`).
   - In `both@spectator`, neither Player 1 nor Player 2 stats are known. The search must find a joint assignment across all 8 active Pokémon.
3. **Failure of Joint Guess Sampling at Turn 6**:
   - Guess generation (`aimFor`, `closestSpread`) samples spreads independently across the unconstrained candidate spaces ($>10^7$ candidate spreads for Kingambit, $>10^8$ for Garchomp).
   - In nearly all sampled joint guesses, Kingambit's Kowtow Cleave leaves Garchomp with $HP > 0.25 \times \text{maxHP}$, causing the simulator on Turn 6 to execute `|-start|p2a: Garchomp|Substitute`.
4. **Failure of Single-Stat Fallback**:
   - When rebuild fails at Turn 6.1, `fallback` attempts single-stat variations (testing stat values 0, 32, 16, etc.) on Garchomp, Kingambit, Floette, Incineroar, and Basculegion one stat at a time while holding other Pokémon at their guessed spreads.
   - Because satisfying both the Turn 4 percentage `25/100` and Turn 6 Substitute failure requires simultaneously aligning Kingambit's Atk, Garchomp's Def, and Garchomp's HP to produce an exact 75% damage ratio on a multiple-of-4 HP pool, 1D parameter searches around inaccurate joint guesses fail to find a valid combination.
   - Fallback hit its rebuild budget on each attempt:
     - Default start: "nothing gets past the line in 8 rebuilds"
     - Usage start: "nothing gets past the line in 8 rebuilds"
     - Wide start: "nothing gets past the line in 32 rebuilds"
     - Widest start: "nothing gets past the line in 128 rebuilds"
5. **Termination**:
