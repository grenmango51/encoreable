## 6. Why `both@spectator` Stalled and Gave Up (Detailed Breakdown)

In `both@spectator`, the inference ran **270 rounds, 850+ rebuilds, and 340,982 probes** over **3,744.2 seconds** in the sweep before terminating with `stop: "stalled"`.

The failure was driven by four interlocking mechanics:

### A. The Spectator Channel (Channel 0) Information Deprivation
1. On Channel 0, every switch-in, attack, and heal line is rendered as an integer percentage (`100/100`, `32/100`, `57/100`, `70/100`, `68/100`, `71/100`).
2. In `infer.mjs` (lines 313–322):
   ```javascript
   if (m && Number(m[2]) !== 100 && (channel === -1 || side === `p${channel}`)) {

   ```
   When `channel === 0`, `side === 'p0'` is never true. Therefore, `exactHp` is **completely empty** for all 12 Pokémon.
3. In `firstGuesses()`, every unknown Pokémon falls back to `defaultSpread(dex, set, undefined)`, which defaults HP Stat Points to **32** for all Pokémon.

### B. The Turn 2 Spread Move Protocol Divergence (`Hyper Voice`)
On Turn 2, `p2b: Primarina` executes `Hyper Voice` (Liquid Voice $\rightarrow$ Water type spread move):
1. In Pokémon Showdown's move data, Hyper Voice has `target: "allAdjacentFoes"`.
2. In `reconstruct.mjs` (line 47):
   ```javascript

   ```
   Because `allAdjacentFoes` is not in `CHOOSABLE_TARGETS`, `reconstruct.mjs` generates no target suffix (`suffix = ''`), emitting `move 1` (or whichever slot Hyper Voice occupies).
3. When Showdown executes `move 1` with no target argument:
   - Showdown resolves the nominal target internally via `resolveTarget()`.
   - On Turn 2, Farigiraf protected (`|-activate|p1b: Farigiraf|move: Protect`).
   - If Showdown resolves `p1b: Farigiraf` as the nominal target, the protocol output is:

     `|move|p2b: Primarina|Hyper Voice|p1a: Golisopod|[spread] p1a`
4. Throughout the search (lines 17, 29, 31, 33, 47, etc.), the reconstructor consistently produced:
   ```
   wanted |move|p2b: Primarina|Hyper Voice|p1b: Farigiraf|[spread] p1a
   got    |move|p2b: Primarina|Hyper Voice|p1a: Golisopod|[spread] p1a
   ```
