### Architectural Fix (`scripts/lib/reconstruct.mjs`)
- **Do Not Simultaneously Pin Downstream `fixes` Across Accuracy Checks in `steerDice` / `resolveTurn` (`reconstruct.mjs:1030–1083, 1881–1914`)**:
  When an accuracy die `d` (`hitStepAccuracy`) is flagged `wrong: true` because the observed log has `|-miss|` (meaning that target was *skipped* in `getSpreadDamage` and `secondaries`), settling `d` changes the number of draws thrown for all subsequent targets of the same spread move. `fixes` should either stop collecting `wrong` draws after the first `wrong` accuracy check of a spread move, or `resolveTurn` should commit only the earliest `wrong` accuracy draw first before re-steering downstream targets on the resulting draw ordinals. Either fix eliminates the `(N + 0, N + 4)` ordinal-shift burn pin completely and unblocks all three views of `mimic:gen9championsvgc2026regmcbo3-2709179827`.
