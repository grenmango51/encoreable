## 7. Architectural Analysis & Mathematical Coupling

### 1. Spread Move Mechanics and PRNG Stream Desynchronization
Under Gen 9 doubles mechanics, when a multi-target move is executed without an explicitly designated target, Pokémon Showdown resolves the action through the following sequence:

1. **Nominal Target Assignment**:
   $$\text{Target}_{\text{nominal}} = \text{getRandomTarget}(\text{user}, \text{move})$$
   where `getRandomTarget` draws from the uniform distribution of adjacent active foes:
   $$\text{Target}_{\text{nominal}} \sim \text{Uniform}(\{p2a, p2b\})$$
   This consumes 1 PRNG call:
   $$R_1 = \text{prng.random}()$$

2. **Per-Target Accuracy Check**:
   For each adjacent foe $t \in \{p2a, p2b\}$, an independent accuracy roll is performed:
   $$\text{Hit}_t = (\text{prng.random}() \times 100 < \text{Accuracy} \times \text{AccuracyMod})$$
   For Heat Wave ($\text{Accuracy} = 90$):
   $$R_{2} < 90 \implies \text{Hit}_{p2a}, \quad R_{3} < 90 \implies \text{Hit}_{p2b}$$

3. **Spread Protocol Emission**:
   Showdown constructs the protocol string as:
   $$\text{Line} = \text{"|move|" } + \text{ident}(\text{user}) + \text{"|" } + \text{move.name} + \text{"|" } + \text{ident}(\text{Target}_{\text{nominal}}) + \text{"|[spread] " } + \text{join}(\{t \mid \text{Hit}_t = \text{true}\})$$

If a single RNG call earlier in the battle is displaced (for example, a secondary effect roll, critical hit check, or damage roll variation in Turns 2–4), the global random stream index $k$ shifts by $\Delta k \ne 0$. Under the shifted stream:
$$R'_1 \ne R_1 \implies \text{Target}_{\text{nominal}} \text{ flips from } p2b \text{ to } p2a$$
$$R'_2 \ge 90 \implies \text{Hit}_{p2a} = \text{false}$$
This produces the exact observed mismatch:
$$\text{Expected: } \text{|move|p1a: Charizard|Heat Wave|p2b: Arcanine|[spread] p2a,p2b}$$
$$\text{Rebuilt: } \text{|move|p1a: Charizard|Heat Wave|p2a: Raichu|[spread] p2b}$$

### 2. Percentage Truncation and Bulk Discretization
In spectator channel 0, all damage transitions are truncated to integer percentages:
$$P_t = \left\lfloor \frac{\text{HP}_{\text{curr}} \times 100}{\text{HP}_{\text{max}}} \right\rfloor$$
On Turn 5:
- Raichu's attack on Charizard deals:
  $$\text{Damage} = \left\lfloor \left( \left\lfloor \frac{22 \times \text{BP} \times \text{SpA}_{\text{Raichu}}}{50 \times \text{SpD}_{\text{Charizard}}} \right\rfloor + 2 \right) \times \frac{\text{Roll}}{100} \right\rfloor$$
  With Charizard's Mega-Y base HP of 78 ($\text{HP}_{\text{max}} \in [153, 185]$), a 1-point difference in SpA or SpD creates non-linear jumps in remaining percentage $P_t$, skipping the required `28/100` and jumping between surviving at `17/100` and outright fainting at `0 fnt`.

### 3. Fallback Tier Starvation Proof
Let $B_l = (\text{probes}_l, \text{backtracks}_l)$ be the search budget at level $l \in \{0, 1, 2, 3\}$.
In `scripts/lib/inference/infer.mjs`:
- Level 3 (`Search 4`) uses budget $B_3 = (32000, 4000)$.
- Fallback is hardcoded to call:
  ```js

  ```
  where $B_1 = (500, 100)$.
Let $T_{\text{pass}}(t)$ be the minimum budget required to resolve the variant/RNG combination of turn $t$.
For this match:
$$T_{\text{pass}}(5) > B_1 \quad \text{and} \quad T_{\text{pass}}(5) \le B_3$$
Because $B_1 < T_{\text{pass}}(5)$, any rebuild executed with $B_1$ is mathematically guaranteed to halt at $t \le 5$ (specifically at line 5.12).
Therefore, for any target turn $t \ge 6$:
$$\text{reach}(\text{rebuild}(\text{guess}, B_1)) = (5, 12) < 6$$
The engine checks:
```js

```
Because $5 < 6$, fallback aborts immediately without exploring the neighborhood of the guess. This proves that fallback on any turn $t \ge 6$ was completely disabled by design whenever Turn 5 required budget tier 2 or 3.
