## 6. Spectator Search Pathology (`both@spectator`)

### Root Cause 1: Two-Turn Move Target Recovery Failure (`recoverChargeTargets`)
In Pokémon Showdown doubles, two-turn charge moves (such as `Electro Shot`, `Solar Beam`, `Meteor Beam`, `Skull Bash`, `Geomancy`, etc.) require a target selection on the charging turn, but Showdown's protocol suppresses the target on the initial turn:
```text
|move|p1a: Archaludon|Electro Shot||[still]
|-prepare|p1a: Archaludon|Electro Shot
```
The target is only revealed on the release turn:
```text
|move|p1a: Archaludon|Electro Shot|p2b: Whimsicott|[from] lockedmove
```
To reconstruct the correct input log, `scripts/lib/reconstruct.mjs` implements `recoverChargeTargets(plans)`:
```js
function recoverChargeTargets(plans) {
  for (const [k, plan] of plans.entries()) {
    for (const side of ['p1', 'p2']) {
      for (const [slot, action] of plan.actions[side].entries()) {
        if (!action || action.target || !action.needsTarget) continue;
        for (const later of plans.slice(k + 1)) {
          const match = later.actions[side][slot];
          if (match?.moveid === action.moveid && match.target) {
            action.target = match.target;
            action.recovered = true;
            action.landsOn = plans.indexOf(later);
            break;
          }
        }
      }
    }
  }
}
```
`recoverChargeTargets` looks ahead into future turns (`plans.slice(k + 1)`) to find the matching action release in `later.actions[side][slot]` and recover the target.

### Root Cause 2: Interaction Between `planSegment` and Prankster `Encore`
On Turn 7, Player 2's Whimsicott has the `Prankster` ability. Because of Prankster, Whimsicott's status move `Encore` moves at priority +1, acting before Archaludon executes its locked move:
```text
|move|p2b: Whimsicott|Encore|p1a: Archaludon
|-start|p1a: Archaludon|Encore
```
In `scripts/lib/reconstruct.mjs:planSegment()`, lines 170–177 handle Encore as follows:
```js
if (kind === '-start' && /Encore$/.test(parts[3] || '')) {
  encored.add(parts[2]);
  continue;
}

if (kind === 'move') {
  if (toID(parts[3]) === 'revivalblessing') reviver = { slot: identSlot(parts[2]) };
  if (encored.has(parts[2])) continue;
  const from = tagsOf(line).from;
  if (from && from !== 'lockedmove') continue;
  ...
  plan.actions[side][slot] = {
    moveid,
    target,
    needsTarget: CHOOSABLE_TARGETS.has(dex.moves.get(moveid).target),
  };
}
```
Notice the fatal flaw:
1. When `-start|p1a: Archaludon|Encore` is encountered, Archaludon is added to the `encored` set (`encored.add('p1a: Archaludon')`).
2. When Archaludon later executes its move:
   `|move|p1a: Archaludon|Electro Shot|p2b: Whimsicott|[from] lockedmove`
   Line 177 checks:
   `if (encored.has(parts[2])) continue;`
3. Because Archaludon is in `encored`, the parser **completely skips** Archaludon!
4. `plan.actions['p1'][slot]` is **never populated** for Archaludon on Turn 7!
5. When `recoverChargeTargets` subsequently runs, `match = later.actions[side][slot]` is `undefined`.
6. Target recovery **fails silently**. Archaludon's action on Turn 6 retains `target = null`.
7. When the reconstructor builds the choice string for Turn 6, an unrecovered target defaults to foe slot 1: `p2a: Basculegion`.
8. When the simulated rebuild reaches Turn 7, Showdown releases the locked move into `p2a: Basculegion`:
   ```text
   wanted |move|p1a: Archaludon|Electro Shot|p2b: Whimsicott|[from] lockedmove, got |move|p1a: Archaludon|Electro Shot|p2a: Basculegion|[from] lockedmove
   ```
