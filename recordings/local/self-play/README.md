# Self-play battles

Battles you played by hand against yourself. `npm run battle` opens two windows as `Player1_<n>`
and `Player2_<n>`, loads a team into each and starts the battle; you choose both sides' moves.
Real decisions with full information, unlike `../scripted/`.

**Goes here:** finish the battle, then run `npm run replay -- --from <its file in runtime/logs>`.
That copies it in here and proves it reproduces. A battle you restored with `npm run live` and
played on goes to `../branched/` instead, and the same command files it there.
