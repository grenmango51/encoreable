# Tournament videos

Broadcasts and VODs of tournaments: other players' games, filmed and published by someone else.
Team sheets are closed unless the broadcast shows them, or the event publishes them.

**Goes here:** the video file, named as `../README.md` says, and a row below. The file itself is
gitignored, so the source link is what lets anyone get it again.
