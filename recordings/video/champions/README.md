# Pokémon Champions videos

Captures from Pokémon Champions itself: your own games recorded off the screen, or battle videos
saved in the game. Your own team is known exactly. Unlike a Showdown replay there is no log, so
every number has to be read off the screen.

**Goes here:** the video file, named as `../README.md` says, and a row below. The file itself is
gitignored and exists only on the machine that recorded it.
