# Full sheets

Your games against a friend, where each of you has the other's complete team sheet, Stat Points
included. That makes them the only replays with a known answer. Reconstructed with both sheets,
every line must match. Reconstructed with `--infer`, the real spreads must survive.

**Goes here:** a replay page from such a game, under the name the site gave it. Both sheets go in
`scripts/fixtures/teams.js` as one set, and the row below names it.
