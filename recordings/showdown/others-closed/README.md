# Other players' games, closed team sheets

Games between two other players where the replay carries no `|showteam|`, such as Bo1 ladder
games. The least-known case there is: both sides' sets are read off the log, and both sides' HP
arrives as a percentage. Run them with `npm run reconstruct -- --from <file> --infer both`.

**Goes here:** a replay page from such a game, under the name the site gave it, plus a row below.
