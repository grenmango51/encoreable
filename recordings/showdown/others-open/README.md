# Other players' games, open team sheets

Games between two other players where the replay carries a `|showteam|` line per side, as every
public Bo3 does. Both teams' species, items, abilities and moves are known, and neither side's Stat
Points. The server publishes a spectator's view, so both sides' HP arrives as a percentage. Run them
with `npm run reconstruct -- --from <file> --infer both`.

The eighteen public Bo3 games in `docs/engineering.md` §7.4 were of this kind. They were scratch
material and are not kept.

**Goes here:** a replay page from such a game, under the name the site gave it, plus a row below.
